# 🐱 GatoXadrezAI

**GatoXadrezAI** é um jogo de xadrez com temática de gatos, criado para unir a estratégia do xadrez tradicional a uma apresentação divertida e interativa.

O tabuleiro e as peças ganham uma identidade felina, enquanto os jogadores continuam aproveitando os movimentos, desafios e decisões clássicos do xadrez.

## ♟️ O jogo

O projeto oferece uma experiência de xadrez com personagens inspirados em gatos, recursos de personalização e diferentes formas de jogar. Entre as experiências disponíveis estão partidas com controle de tempo e opções para ajustar o jogo às preferências de cada pessoa.

## 👤 Login e experiência do jogador

O GatoXadrezAI também contempla uma experiência de **login**, permitindo ao jogador acessar os recursos de conta disponibilizados pelo jogo. A disponibilidade de funcionalidades associadas à conta pode depender da conexão com a internet e da configuração dos serviços online.

## 🛠️ Como foi feito

O jogo foi desenvolvido como uma aplicação web interativa, utilizando **HTML, CSS e JavaScript**. O projeto foi pensado para funcionar diretamente no navegador, com atenção à aparência, à usabilidade e à experiência em computadores e dispositivos móveis.

Seu desenvolvimento combina as regras tradicionais do xadrez com uma identidade visual própria, animações e recursos interativos, incluindo uma estrutura preparada para funcionalidades de conta e login.

## 🎯 Objetivo

Oferecer uma maneira diferente e envolvente de jogar xadrez, preservando a essência do jogo e tornando a experiência mais descontraída por meio de personagens felinos.
